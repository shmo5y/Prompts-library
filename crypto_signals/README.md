# محلل إشارات العملات الرقمية لـ IQ Option

يعطيك **اتجاه الدخول (Call/Put) ووقته بالثانية ووقت الانتهاء** لأزواج مثل BTC/USD وETH/USD، وأنت تنفّذ يدوياً.
يحلل بيانات حقيقية من Binance (احتياطياً Bybit ثم OKX) بدون مفاتيح API.

## التشغيل
```bash
pip install -r requirements.txt

# 1) الأهم: اختبر الاستراتيجية على بيانات تاريخية حقيقية قبل أي مال
python main.py backtest --pairs BTC/USD,ETH/USD,XRP/USD --tf 5m --bars 8000 --payout 0.85

# 2) تشغيل الإشارات المباشرة (ينتظر إغلاق كل شمعة ويطبع الفرص)
python main.py scan --tf 5m --threshold 70 --expiry-bars 1 --tz Asia/Riyadh
```
- `--tf`: فريم التحليل (1m/5m/15m). يُنصح 5m أو 15m (ضجيج أقل من 1m).
- `--expiry-bars`: مدة الصفقة بعدد الشموع (5m × 1 = 5 دقائق).
- `--threshold`: حد قوة الإشارة (أعلى = إشارات أقل وأنقى). اختره من نتائج الباكتست.
- البرنامج يقيّم إشاراته تلقائياً بعد الانتهاء ويعرض نسبة النجاح الحية.

## كيف يقرر؟
تقاطع عدة عوامل (نقاط -100..+100): اتجاه EMA + توافق الفريم الأكبر (1h) + MACD + ارتداد RSI + شمعة تأكيد (نظام اتجاه)،
أو تطرّف بولينجر + RSI + شمعة انعكاس (نظام تذبذب)، مع فلتر ADX وفلتر تذبذب ATR.

## الدخول
الإشارة تظهر عند **إغلاق** الشمعة، ادخل في **أول ثواني الشمعة التالية** (الوقت مكتوب في الإشارة). التأخر يضعف النتيجة.

## تنبيه صريح عن الدقة
- لا يوجد نظام دقيق 100%، ولا أستطيع ضمان ربح. الدقة الحقيقية تظهر فقط في الباكتست على بيانات حقيقية.
- عائد IQ Option ~85% يعني أن نسبة التعادل ≈ **54.1%**؛ أي نتيجة أقل منها خسارة مؤكدة مع الوقت.
- لا تثق بعيّنة التدريب؛ الحكم لعمود "خارج العيّنة" و"أدنى حد موثوق". إن لم يتجاوز التعادل فلا تتداول بالمال الحقيقي.
- ابدأ بحساب تجريبي، وخاطر بنسبة صغيرة (1–2%) من الرصيد، وتجنب وقت الأخبار الكبرى.
- تم التحقق من خلو الكود من التسرّب المستقبلي: على بيانات عشوائية النتيجة ≈ 50%.
